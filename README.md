# 2048
Классическая игра **2048**, разработанная на платформе **.NET 10** с использованием графического интерфейса **WPF**
Цель игры — объединять плитки с одинаковыми числами, чтобы получить плитку с номиналом «2048». 

## Как играть 
Используйте **стрелки на клавиатуре**, чтобы перемещать плитки на игровом поле.
При столкновении двух плиток одинакового номинала они соединяются в одну, а их значения суммируются.
Игра заканчивается, если на поле не остается свободных ячеек 

Вы можете изменить **цветовую тему** на 1 из 10 набор цветов.
